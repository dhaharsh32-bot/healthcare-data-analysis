# Hospital Readmission Analysis of Diabetic Patients

## Project Overview
This project analyzes hospital readmission patterns among diabetic patients using an Excel dashboard.

## Project Objectives
- Analyze hospital readmission distribution.
- Compare readmission patterns across age groups.
- Explore hospital stay and readmission rates.
- Analyze insulin treatment categories against readmission outcomes.
- Present key indicators through data visualization.

## Dataset
- Total encounters reported in the dashboard: 101,766
- Domain: Healthcare analytics
- Subject: Diabetic patient hospital encounters

## Key Dashboard Insights
- Not readmitted: 54%
- Readmitted within 30 days: 11%
- Readmitted after 30 days: 35%

*These figures are reported from the dashboard and should be validated against the source data before drawing conclusions.*
